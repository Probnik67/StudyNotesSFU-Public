# StudyNotesSFU

StudyNotesSFU — Android-приложение для работы с учебным расписанием, конспектами, домашними заданиями и подготовкой к занятиям.

## Current version

v0.8.58

## Main features

- загрузка актуального расписания СФУ;
- поддержка 1-й и 2-й подгрупп;
- просмотр занятий по датам;
- создание и хранение конспектов;
- работа с несколькими фотографиями конспекта;
- домашние задания и сроки выполнения;
- локальная статистика использования OpenAI;
- подключение к StudyNotesSFU Backend;
- проверка обновлений приложения.

## Security

Секретные данные не хранятся в исходном коде приложения.

Запросы к защищённым endpoint backend подписываются ключом устройства, создаваемым в Android Keystore.

Release signing настраивается через переменные окружения:

- STUDYNOTES_STORE_FILE
- STUDYNOTES_STORE_PASSWORD
- STUDYNOTES_KEY_ALIAS
- STUDYNOTES_KEY_PASSWORD

Значения этих переменных не должны добавляться в репозиторий.

## Privacy

Этот публичный репозиторий содержит только исходный код приложения и необходимые ресурсы.

В него не включаются пользовательские конспекты, домашние задания, локальные базы данных, скриншоты, visual evidence, APK, архивы, signing keys и файлы окружения.

Группа, используемая в опубликованном исходном коде по умолчанию, является демонстрационной.

## Build

Проект использует Gradle Wrapper.

Для Windows:

    gradlew.bat assembleDebug

Для Linux/macOS:

    ./gradlew assembleDebug

Для локальной Android-сборки может потребоваться `local.properties` с путем к Android SDK. Этот файл не должен добавляться в Git.

## Backend

Клиент взаимодействует с отдельным StudyNotesSFU Backend.

Секрет OpenAI API должен находиться только на стороне backend и не должен встраиваться в Android-приложение.
